# usine-bots

Code de l'usine de trading de Richard : bots Moonshot et Smart Peanut (moonshot2/), Recolteur T6 (recolteur/),
tableau de bord et telecommande (tableau/), usine de recherche (usine/, sp-replay/).

- `main` : deploye automatiquement sur le VPS par le Deployeur apres tests (deploy/cibles.json).
- `rapports` : etat du VPS publie chaque heure (aucun secret).
- `jobs/`, `messages/`, `deploy/env/` : travaux, messages Telegram et variables autorisees.
